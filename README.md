# Thailand Election Dashboard

A Next.js dashboard for visualizing Thailand's eligible voter data by region.

## Run Locally

**Prerequisites:** Node.js 18+

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) to view the app.

## Build for Production

```bash
npm run build
npm start
```

## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Charts:** Recharts
- **Maps:** react-simple-maps
- **Icons:** Lucide React
## Features

- Interactive Thailand map with regional data
- Dashboard with KPI cards showing voter statistics
- Filter by region (Bangkok, Central, North, Northeast, South)
- Top 10 districts with highest eligible voters
- Searchable district table
- Responsive design
